# Industry card images

Drop real photography or 3D renders into this folder using these EXACT
filenames — the component already points to them, so no code changes
are needed once the files exist.

| File                  | Industry      |
|------------------------|---------------|
| healthcare.jpg          | Healthcare    |
| jewellery.jpg            | Jewellery     |
| manufacturing.jpg       | Manufacturing |
| education.jpg            | Education     |
| hospitality.jpg          | Hospitality   |
| restaurants.jpg          | Restaurants   |
| real-estate.jpg          | Real Estate   |
| smes.jpg                  | SMEs          |

Recommended: 1600×1600px minimum, JPG, under ~400KB each (compress with
squoosh.app or similar) so the grid stays fast.

Until a file is added, that card shows a mood-matched dark gradient
instead of a broken image — it degrades gracefully, no visual bug.
